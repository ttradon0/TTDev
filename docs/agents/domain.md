## Before exploring

Read root `CONTEXT.md` and relevant records under `docs/adr/`. If a context file does not exist, proceed silently; `/domain-modeling` creates it when terminology or a decision is resolved.

## Vocabulary

Use terms as defined in `CONTEXT.md`. Flag contradictions between a proposed change and an existing ADR rather than silently overriding the decision.
