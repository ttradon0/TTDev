# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues for `ttradon0/TTDev`. Use the `gh` CLI; the `origin` remote identifies the repository.

## Conventions

- Create and read issues with `gh issue create` and `gh issue view`.
- Use GitHub Issues as the tracker for specs and implementation tickets.
- PRs are not a triage request surface.
- Apply the five labels listed in `triage-labels.md` when triaging.
- For wayfinding, use a map issue with child issues and native GitHub issue dependencies where available.
